一、基本信息

接口版本： v1

请求方式： POST

数据格式： JSON

接口前缀：

/api/in/v1

二、统一返回结构

{
  "code": 0,
  "msg": "Success",
  "data": {}
}
字段 说明
code 返回码，0 表示成功
msg 返回信息
data 业务数据

三、错误码说明

编码规则：41xxx 表示请求校验错误，42xxx 表示商户错误，43xxx 表示订单错误， 44xxx 表示风控错误，45xxx 表示支付通道错误，50xxx 表示平台服务错误。
code 说明
0 成功
41001 请求参数错误
41002 签名校验失败
41003 请求 IP 不在商户白名单
41029 请求过于频繁
42001 商户不存在
42002 商户服务不可用或对应业务已关闭
42003 商户账户余额不足
43001 订单不存在
43002 商户订单号已存在
44001 交易被风控拒绝
45001 当前无可用支付通道
50001 平台内部错误
50002 平台维护中，服务暂不可用

四、签名规则

签名算法： MD5
参数按字段名 ASCII 升序排序
空值参数不参与签名
signature 字段不参与签名
拼接商户密钥 key
MD5运算上一步得到的字符串并大写 
callbackUrl=https://merchant.example.com/callback&clientIp=203.0.113.10&customerPhone=9876543210&merchantId=1001&merchantOrderId=xxx&orderAmount=10000&key=YOUR_KEY
MD5 → 大写

五、代收接口（收款）

1️⃣ 创建代收订单 POST

/api/in/v1/ds/ld
字段 类型 必填 说明
merchantId int 是 商户号
merchantOrderId string 是 商户订单号（唯一）
orderAmount int 是 支付金额（单位：分）
clientIp string 是 用户的真实IP
callbackUrl string 是 支付结果通知地址
signature string 是 签名
customerId string 否 商户用户ID
customerName string 否 用户姓名
customerPhone string 是 印度本地手机号（强烈建议）
customerEmail string 否 邮箱
deviceFingerprint string 否 设备ID
metadata string 否 透传参数

返回参数

字段 说明
merchantId 商户号
platformOrderId 平台订单号
merchantOrderId 商户订单号
checkoutUrl 支付链接
link 深度链接（可选）；仅通道支持时返回，否则为空

返回示例

{
  "code": 0,
  "msg": "Success",
  "data": {
    "merchantId": 10000,
    "platformOrderId": "PO01293091823",
    "merchantOrderId": "MO192834091287491",
    "checkoutUrl": "https://pay.example.com?orderid=PO129417890257",
    "link": "upi://pay?pa=example@upi"
  }
}

六、代付接口（出款）

1️⃣ 创建代付订单 POST

/api/in/v1/df/ld
字段 类型 必填 说明
merchantId int 是 商户号
merchantOrderId string 是 商户订单号（唯一）
orderAmount int 是 金额（单位：分）
clientIp string 是 发起请求的客户端真实 IP
customerName string 否 收款人姓名
customerPhone string 是 印度本地手机号（强烈建议）
customerEmail string 否 邮箱地址，格式需正确
payoutMethod int 是 代付方式：1=银行卡，2=UPI
beneficiaryAccount string 是 收款账号
ifscCode string 条件必填 银行支付必填，IFSC码
beneficiaryBank string 条件必填 银行支付必填，银行名称
callbackUrl string 是 支付结果通知地址
signature string 是 签名，MD5，规则同代收
customerId string 否 商户用户 ID，可选
deviceFingerprint string 否 设备 ID，可选
metadata string 否 透传参数，可选

请求示例

{
  "merchantId": 10000,
  "merchantOrderId": "qweoi1011",
  "orderAmount": 10000,

  "customerName": "john",

  "customerEmail": "john@gmail.com",
  "payoutMethod": 1,
  "beneficiaryAccount": "1234567890",
  "ifscCode": "HDFC0001234",
  "beneficiaryBank": "HDFC Bank",
  "callbackUrl": "https://www.example.com",
  "signature": "ASJ654564SDD",
  "customerId": "user123",
  "deviceFingerprint": "aslkdjajilsd",
  "metadata": "po"
}

返回参数

字段 说明
merchantId 商户号
platformOrderId 平台订单号
merchantOrderId 商户订单号

返回示例

{
  "code": 0,
  "msg": "Success",
  "data": {
    "merchantId": 10000,
    "platformOrderId": "PO12093812309123",
    "merchantOrderId": "MO1293810928309"
  }
}

七、余额查询

/api/in/v1/sh/ye
字段 类型 必填 说明
merchantId int 是 商户号
signature string 是 签名，MD5签名规则同代收代付

请求示例

{
  "merchantId": 1001,
  "signature": "SLKJLKSFJ1293123"
}

返回参数

字段 类型 说明
merchantId int 商户号
availableFunds int 可用余额（单位：分）
pendingFunds int 待结算余额（单位：分）
lockedFunds int 冻结金额（单位：分）

返回示例

{
  "code": 0,
  "msg": "Success",
  "data": {
    "merchantId": 1001,
    "availableFunds": 100000,
    "pendingFunds": 100000,
    "lockedFunds": 10000
  }
}
说明：
- 所有金额单位均为 分，商户可自行换算为元/卢比。
- 可用余额 = 可直接使用的资金
- 待结算余额 = 已到账但未结算资金
- 冻结金额 = 风控/异常冻结资金

八、回调说明

1️⃣ 代收回调（Pay Callback）

POST 创建订单时传入的 callbackUrl
字段 类型 说明
merchantId int 商户号
platformOrderId string 平台订单号
merchantOrderId string 商户订单号
orderAmount int64 订单金额（单位：分）
orderStatus int 订单状态，参考订单状态表
statusMessage string 错误信息或提示
metadata string 透传参数，原样返回
signature string 签名，MD5校验

回调示例

{
  "merchantId": 10000,
  "platformOrderId": "PO1293891283912",
  "merchantOrderId": "MOq1029301293",
  "orderAmount": 10000,
  "orderStatus": 3,
  "statusMessage": "success",
  "metadata": "pay",
  "signature": "SKJDLKSJ91283"
}
注意事项：
- 回调可能重复，请商户幂等处理
- orderAmount 单位：分
- orderStatus 对应订单状态枚举
- signature 验签规则与接口请求一致，signature 本身不参与签名

2️⃣ 代付回调（Withdraw Callback）

POST 创建订单时传入的 callbackUrl
字段 类型 说明
merchantId int 商户号
platformOrderId string 平台订单号
merchantOrderId string 商户订单号
orderAmount int64 订单金额（单位：分）
orderStatus int 订单状态，参考订单状态表
statusMessage string 错误信息或提示
metadata string 透传参数，原样返回
transactionReference string 银行打款凭证（UTR号）
signature string 签名，MD5 校验

回调示例

{
  "merchantId": 1001,
  "platformOrderId": "PO1098230918823",
  "merchantOrderId": "MO0qq92031982391",
  "orderAmount": 10000,
  "orderStatus": 3,
  "statusMessage": "success",
  "metadata": "payout",
  "transactionReference": "UTR12032901923",
  "signature": "SKJDHHJKLSD0909"
}
注意事项：
- 回调可能重复，请商户幂等处理
- orderAmount 单位：分
- orderStatus 对应订单状态枚举
- transactionReference 仅代付成功时返回，可作为银行打款凭证
- signature 验签规则与接口请求一致，signature 本身不参与签名
注意： 回调可能重复推送，请商户做幂等处理
